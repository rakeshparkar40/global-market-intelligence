Update your existing Streamlit app:
1. Extract this ZIP on your computer.
2. Open the GitHub repository connected to your Streamlit app.
3. Replace the existing app.py with this new app.py.
4. Upload/replace requirements.txt.
5. Create a folder named .streamlit in the repository root, then upload config.toml inside it.
6. Commit changes. Streamlit Community Cloud should redeploy automatically.
7. If needed, use Manage app > Reboot app.

Keep app.py and requirements.txt in the repository root.
